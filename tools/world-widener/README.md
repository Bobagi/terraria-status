# world-widener

One-off tool used on 2026-11-03 to double the width of the live world `Hyperborea`
from 4200x1200 (small) to 8400x1200, keeping the height. The original world stays on the
left untouched; a complete small world generated by the real generator (vanilla plus every
mod on the server), with Crimson instead of Corruption, fills columns 4200-8399.

It is a temporary server-side tModLoader mod (`WorldWidener`). It ran only on a scratch
copy of the server data, never on the live server.

## How it was done

1. Scratch server (`run.sh`, same image and mods, no published port) on a copy of the data.
2. `ww info` / `ww dump` on the copy of Hyperborea: ore tiers, altars smashed, chests, NPC
   homes, and a tile grid that `render.py` turns into a PNG.
3. New small world generated with `WW_GEN_EVIL=crimson` and a chosen seed. The image
   default seed is `Docker`, the same seed Hyperborea was made with, so a seed has to be
   passed (`TMOD_WORLDSEED`). Seed `1653267986` was picked because its layers match
   Hyperborea's (surface 337 on both, caverns 457 vs 445).
4. `ww hardmode 107 222 111 4` on the new world: the Wall of Flesh conversion (hallow and
   crimson stripes) plus the ores of 4 smashed altars, with Hyperborea's ore choices
   (Cobalt, Orichalcum, Adamantite).
5. `ww export /io/gen-export 0`: raw tile data (tModLoader's own tile structs) plus chests
   and their items (ItemIO, modded items included).
6. `ww import /io/gen-export 8400` on Hyperborea, then `save`. In memory: width grows to
   8400 (the tilemap is always allocated at 8401x2401), the new world is pasted at x=4200,
   the hidden border columns of both worlds are replaced, both middle oceans become a
   grassy land bridge (trees and plants grown with the game's functions), the four sea
   chests of the new world are set down on the new ground with their items, and the
   underground seam is blended with the generator's own `TileRunner` blobs and caves.
7. `ww swapores 4200 6:167,8:169,107:221,222:108,111:223` (same day, after the import):
   every world rolls one ore of each pair, so the new half got the other one of each pair
   Hyperborea has (Iron to Lead, Gold to Platinum, Cobalt to Palladium, Orichalcum to
   Mythril, Adamantite to Titanium; it already had Tin, Tungsten and Crimtane). The merged
   world has all 16 ores: Hyperborea's on the left, the alternates on the right.
8. Reload from disk to check: width 8400, 297 chests (117 old intact + 180 new), 92 signs,
   14 tile entities, 38 town NPCs with the same homes, world flags unchanged.

## Rebuild

`build.sh` compiles the mod with the server's tModLoader (installs a .NET 8 SDK into a
throwaway container). Paths in the scripts point at the scratch dir `/opt/terraria-widen`.

Backups of the world before the change:
`/root/terraria-world-backup-pre-widen-final-20261103/` (the save the widening started from)
and `gdrive:terraria-backups/terraria-world-backup-pre-widen-20261103.tar.gz`.
